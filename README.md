# rotflix-kotlin
This is the Android version of our Mobile Apps 1 project.
Built with Kotlin and Jetpack Compose, the app lets users search for movies and TV shows via the TMDb API
.

📱 Features

Search Page – enter a title and trigger a search

Result Page – browse a list of matching movies/series

Detail Page – view detailed info about a selected item (title, overview, etc.)

🛠️ Tech Stack

Language: Kotlin

UI: Jetpack Compose (Material 3)

State Management: ViewModel + State

API: TMDb (The Movie Database)
